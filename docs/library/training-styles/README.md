# Training-styles library

Reference guides the skills cite. Nothing here prescribes Andy's training; the rules that do live in `.claude/skills/principle-*`. Read a guide when a principle points to it or when a question needs the source.

| Folder | What it is | Status |
|---|---|---|
| `vertical-jump/` | THP + Vertical Jump Bible: assessment (explosive-strength deficit), plyo progressions, contact budgets, approach technique, peaking. Sources: THP ebook, VJ Bible v2 | complete |
| `dylan-shannon/` | POWERJACKED: wave progression, 7-day template, upper-body structure | complete |
| `matt-smith-flexibility/` | Flexibility as a skill: ladder, stacking, loaded/isometric method, scheduling. Fully worked for the side split; deep squat / bridge / pike / front split sections are TODO | partial |
| `catalyst-athletics/` | Olympic-lifting program structure, position tests, substitutions | complete |
| `concepts/` | Cross-style frameworks: arc decomposition, periodization, session design, assessment | reference |
| `exercises.md` | Exercise catalog (names should match Supabase `exercises.name`) | reference |
| `diagrams/` | Cross-style diagrams | reference |

Conventions: one folder per style, `guide.md` (the methodology, with section numbers the skills cite) + `exercise-selection.md` + `sources/` (raw material). Add a new style only when a principle skill needs to cite it.
