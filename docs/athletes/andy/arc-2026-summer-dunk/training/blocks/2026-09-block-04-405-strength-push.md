# Block 04 — 405 STRENGTH PUSH  *(W19–W24 · v9 split · DNT-aligned)*

> **New block, opened 2026-09-27.** Per Andy's stated direction: **strength-first to a 405 back squat, layering in speed + reflexive work**, then hand the jump/dunk specialization to **THP** in a later block. The dunk is *parked* — not the goal here. See memory `next-arc-405-squat-direction`.

## Purpose

Drive the **back squat to 405** while progressively **re-introducing speed + reflexive work** (the reactive quality that went untrained in Block 3). This is an honest strength-peaking block: the squat is the hero lift and gets a dedicated intensity ramp to a max attempt; everything else supports or holds. The coach's DNT Oly work continues on the fixed Oly days. THP (jump specialization) comes *after* this block.

## The honest 405 math

- Back-squat e1RM peaked **~366–380** in Block 3; true 1RM ≈ **~375–380**.
- 405 is **+25–30 lb on a true 1RM** — a 2–4 month project, not one block (advanced lifters add 1RM slowly).
- **This block = the volume-accumulation base** (run on the volume-biased wave you always keep). It builds the strength; the **405 max attempt comes after, via a short 2-week peak** bolted on later (or timed with the THP handoff). No forced max single here.

## The squat progression (Sunday back squat)

**Permanent undulating wave, volume-biased** (updated 2026-09-27). The wave is a **permanent fixture** — never replaced with linear/peak programming (see memory `squat-wave-permanent-volume-bias`). This block leans it toward **higher volume**: rep bracket rotates weekly (4/6/8/10), **sets 2–4**, records banked per bracket. So Block 4 is a **volume-accumulation phase of the 405 road** — it builds the base. The **405 max attempt is a later milestone** (a short dedicated peak after this block, or timed with the THP handoff), *not* forced into W24 — you can't express a true 1RM out of a pure volume block, and you'd rather keep the wave than run a peak.

Loads off a ~375–380 working max — **RPE-gated**: chase each week's rep-bracket record; if a week hits ≥RPE 9.5, bank the PR you got. Volume stays high (75–85%); **no singles this block.** W24's 4×4 @320 is a strength *checkpoint*, not the 405 attempt.

**On the 405 itself:** this volume base is step 1 of a 2–4 month road. When you're ready to test it, we bolt a **short 2-week peak** onto the front of a later block (or time it with the THP handoff) to express the max — the wave stays, the peak is a brief add-on, not a replacement.

## Speed + reflexive ramp (layered in — Mon/Fri finisher)

The dedicated reactive stimulus, ramped so it *builds* without stealing recovery from the squat peak:

| Weeks | Reactive finisher (after upper lifting) |
|-------|------------------------------------------|
| **W19–W20** | Re-entry: Box Jump 3×3 + Sprints 3×20yd @ 90% |
| **W21–W22** | Build: Approach Jump 4×3 + Depth Jump 3×4 + Sprints 4×20yd |
| **W23–W24** | Sharpen (low volume during squat peak): Approach Jump 3×3 + Sprints 3×20yd — potentiation only |

Rationale: this re-opens the RFD/SSC quality (VJ §3) as a *base* for the future THP jump block — not peaked here, just consistently present and progressing. Pull it back in W23–W24 so it doesn't compete with the 405 attempt.

## How the rest of the week holds

- **Split unchanged (v9):** Sun Heavy Lower (squat push) · Mon Heavy Upper (+ reactive) · Tue Oly + mobility legs · Wed BJJ · Thu Oly + front squat · Fri Oly + upper (+ reactive) *(opt)* · Sat *(opt)*.
- **Front squat (Thu):** stays **moderate/supportive** (3×4–5, RPE 7–8) — it feeds the squat without competing; on weeks the coach drops a clean+front-squat complex, that covers it.
- **Bench + pull-up (Mon):** hold their own wave — maintain, don't chase (recovery budget goes to the squat).
- **Coach DNT Oly:** re-homes as always (snatch→Tue, clean/jerk→Thu, jerk→Fri); coach back squat + deadlifts dropped (your Sunday squat is the priority now).

## Measurement (the gaps from Block 3 — fix them here)

- **Daily bodyweight log** — non-negotiable this block. +30 lb of squat at stable BW vs. via mass is a completely different result for a future jumper.
- **A jump metric** (CMJ or approach touch) every 2 weeks — baseline for the THP handoff.
- **Squat top sets logged** every Sunday — the whole block is a PR chase.

## THP handoff gate

When the squat lands ~395–405 **and** the reflexive base is in (reactive finisher running consistently, jump metric trending), **reach out to THP** to run the jump/dunk specialization as Block 5. That's the plan: strength now, jump then.
