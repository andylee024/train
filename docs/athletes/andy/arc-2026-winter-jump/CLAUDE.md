# CLAUDE.md — Winter Jump arc

Read on every session start. Build and explain workouts with the repo skills `build-workout-plan` + `principle-*` (they override this file where they conflict).

- **Hot path:** `training/active/current-week.md` → today's date → that day's table. Core days Sun/Mon/Tue/Thu; Fri/Sat are bonuses. If a day was missed, resume at the current week; never double up.
- **Tuesday is the priority session.** It always opens with approach drills and max approach jumps; the best touch goes in the set note as `touch 10'4"`.
- **Coach lifts** (`coach-programs/`): heavy clean day → Sun 1a · clean + pull → Thu 1a/1b · snatch / light → Tue 4a after jumps · jerk / overhead → Fri 1a · back squat skipped · heavy front squat = that week's squat, to a box.
- **Injury rules:** right hip — box above the pinch, no deep Cossacks / loaded 90/90 back-leg, pain ≥ 3/10 → out for the week. Left shoulder — no barbell overhead above 3/10, landmine / DB neutral instead. Knee ≥ 3/10 → no depth jumps. Propose swaps, don't dictate.
- **Flex skills:** hip IR (Mon, 20') · overhead (Fri, 20'). Nothing deep within 48 h of Tue/Sat.
- **Logging:** sets to Supabase; bodyweight to `daily_metrics` every Sunday; never write executed sets into markdown.
- **Escalate:** two core sessions missed in a row · touch flat 3 weeks · squat top set −5% two weeks · pain ≥ 3/10 for 5+ days.
