# Block P — Power + Approach (W1–W4 · Nov 8 – Dec 5, 2026)

## Purpose
Learn the approach and make the strength fast. Jumping is the main lift; the Olympic lifts run as power work with the coach; the squat is held at two sets to a box; flexibility starts as a skill (hip IR, overhead).

## Goals (binary, scored W4)
1. **Baseline captured W1** (standing reach, standing vertical, approach touch best of 5, seated hip IR both sides, Taylor's pose cm, supine overhead test, heel-elevated squat test, 40 kg OHS) and **touch logged every Tuesday**.
2. **Approach touch +1½–2" over baseline at the W4 retest.**
3. **Four core sessions a week in every week** (Sun L1 · Mon U1 · Tue J1 · Thu P1).

## Progression
- Plyos: one variable at a time — volume W1–3 (depth 3x3 → 3x4), box height and run-in wait for Block R.
- Jump squat 75 → 85 → 95 lb (20–25% of squat max).
- Upper: record attempt every session (+10 at RPE ≤ 8, +5 at 8.5–9, repeat on a miss) + 2 back-offs.
- Squat: wave at 2 sets, RPE ≤ 8, box above the pinch. Beat a record only if the hip is quiet.
- **W4 = light + retest** (half volume, all tests repeated).

## Coach (DNT wk1–4) — `principle-dnt-olympic-lifts`
Heavy clean day → Sun 1a · clean + pull → Thu 1a/1b · snatch / light → Tue 4a after jumps · jerk / overhead → Fri 1a · her back squat skipped · her heavy front squat = that week's squat (box) · accessories into block 3. Source: `coach-programs/dnt-wk01-02_arc-W01-W02.pdf` (+ wk3–4 when it lands).

## Rules
- Right hip: squat to a box above the pinch; no deep Cossacks / loaded 90/90 back-leg; pain ≥ 3/10 → movement out for the week; physio booked.
- Left shoulder: no barbell overhead above 3/10 → landmine / DB neutral.
- Knee ≥ 3/10 → no depth jumps that week.
- Touch flat 3 weeks → Sunday squat 1 set, +4 approach jumps Thu. Squat top set −5% two weeks with touch rising → add a set; with touch flat → halve Tuesday for a week.
- Busy week: keep Tue, Sun, Mon, Thu. Fri/Sat skipped is by design.
- W3 holds Thanksgiving (Thu Nov 26): if Thu is lost, run P1 Fri and skip U2.

## Measurement
Tue: best touch in the set note (`touch 10'4"`). Sun: bodyweight (189 → 187 by W4). W1 + W4: full test battery above.
